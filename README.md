# CSS Selectors Practice

This project demonstrates the use of CSS selectors to style different HTML elements using classes, IDs, element selectors, and anchor styling.

## Project Overview

The page contains:
- headings styled with classes and IDs
- paragraphs with element and ID selectors
- links with custom colors and background
- list items styled using standard selectors
- a simple page layout to practice CSS targeting

## Files

- `index.html` - HTML structure for the page
- `style.css` - styling rules for the page

## How to View

1. Open the project folder in your browser.
2. Open `index.html` in a browser.
3. You will see the styled webpage based on the CSS rules in `style.css`.

## CSS Concepts Covered

- Element selectors: `p`, `h1`, `h4`, `a`
- Class selectors: `.head`
- ID selectors: `#bglime`, `#para`, `#pg`
- Text color styling
- Background color styling
- Font size control

## Notes

This is a beginner-level CSS exercise focused on understanding how selectors work and how different elements can be styled individually or collectively.
